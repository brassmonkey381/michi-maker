# Michi-Maker or Cardrake?

*By Brian, who builds Michi-Maker. Written November 15, 2026. I have a stake in this, so weigh
it that way, and check Cardrake's own site before you decide.*

I get asked how Michi-Maker compares with Cardrake. They overlap less than the names "binder
planner" suggest. [BRIAN: one sentence on when you first came across Cardrake, or delete.]

## The short version

Cardrake is built around **finishing sets**. Michi-Maker is built around **making pages look
like something**: a page about one Pokémon, one colour, one artist, or one picture cut across the
pockets. Both let you plan a binder in the browser for free.

## What each one does

**Cardrake** (their homepage, 2026-11-15):

- Calls itself "the free Pokémon TCG binder planner".
- Set pages with card lists, rarities and images, and set guides with chase cards, prices and
  binder layout advice.
- Master set planning across expansions, and printable placeholders for the cards you are missing.
- A paid Collector plan adds collection tracking (owned and wanted, completion, a portfolio view).
  No price is shown on the homepage.
- Says "15,000+ collectors" use it.

**Michi-Maker** (as of 2026-11-15):

- Free in the browser; you can start a binder without an account.
- Pages are composed: put one card in a pocket and fill the page around it by Pokémon, evolution
  line, artist or colour, or slice one picture across several pockets.
- Set binders too: pick a set and get every card in number order, one pocket each, with set
  planners for 26 sets that count pages and sheets per binder size.
- Print true-size fill sheets (63 by 88 mm) to slide into the pockets until the real cards arrive.

## Pick Cardrake if

- Your goal is a **complete master set** and you want the guide, the placeholders and collection
  tracking in one place. That is the centre of what Cardrake does.
- You want a large, established user base and set guides written around chase cards.
- You do not care how a page looks, only that every slot is accounted for.

## Pick Michi-Maker if

- You want pages that read as **one picture**: a Gengar page, a page in one colour, an artist's
  page, art sliced across pockets. That is the michi method, and Michi-Maker is built for it.
- You want to see the page with real card art before you buy or move a single card.
- You want to start without making an account.

## Use both

Plenty of collectors keep a set binder and a separate display binder. [BRIAN: is this you? One
line about your own binders, or delete.] Cardrake for the set checklist, Michi-Maker for the
pages you show people, is a reasonable split.
